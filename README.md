# My_first_dev_ops_practic
репозиторий содержит первые попытки погружения в девопс

# В репозитории собраны манифесты терраформ для работы с Яндекс Облаком
# и файлы конфигурации ansible для настройки виртуальных машин

Терраформ разворачивает три ВМ. Две из них работают исключительно внутри VPC

Одна ВМ с публичным IP - бастион, прокси и балансировщик

На двух других работают веб-сервера на портах 3000

# !ВНИМАНИЕ! #
Терраформ выводит в консоль ip адреса ВМ. Их необходимо вручную вставить в инвентарь ansible

Файл для веб-страницы задается в ansible_practicum/nginx_custom/files/index.html
